# Coin Runner

A Unity 6 Universal 2D platformer built to match the Lab 02 Coin Runner requirements. The project targets Unity `6000.3.26f1` and uses the Universal 2D template.

## Open the project

1. Install Unity `6000.3.26f1` with the Universal 2D template support.
2. In Unity Hub, choose **Add project from disk** and select this folder.
3. Open `Assets/Scenes/CoinRunner.unity` if Unity does not open it automatically.
4. Press **Play**. Move with **Left/Right** or **A/D**, jump with **Space**, collect coins, avoid spikes and the gap, then reach the goal flag.

See [UNITY_GUIDE.md](UNITY_GUIDE.md) for the scene structure and a step-by-step checklist. See [MASTER_PROMPT.md](MASTER_PROMPT.md) for a reusable prompt to recreate and validate a project from the lab PDF.
